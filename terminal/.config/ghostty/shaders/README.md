# How to install custom shaders for ghostty

Go to https://github.com/KroneCorylus/ghostty-shader-playground/tree/main/public/shaders to get the
shaders, copy the raw text and save it in ~/.ghostty/shaders then use it in the config as shown
below.

```config

custom-shader = shaders/cursor_smear.glsl
```
