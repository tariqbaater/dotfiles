## Key Locations

| Path | Purpose | Key Contents |
|------|---------|--------------|
| `init.lua` | Neovim entry point. Executed first. | 3 require() calls. Must be kept minimal. |
| `lua/tariq/lazy.lua` | Plugin manager bootstrap. | lazy.nvim clone/load logic, `mapleader` setup, `lazy.setup()` with imports. |
| `lua/tariq/core/` | Base configuration that is not plugin-specific. | `options.lua` (all `vim.opt`), `remap.lua` (all global keymaps), `commands.lua` (all autocommands and `:UserCommand`s). |
| `lua/tariq/plugins/` | All plugin specs. One file per plugin or concern. | 39 plugin spec files, each returning a lazy.nvim table. |
| `lua/tariq/plugins/lsp/` | LSP-related plugin specs. | `mason.lua` (LSP/tool installer config), `lsp.lua` (cmp-nvim-lsp + capabilities). |
| `after/` | Filetype or plugin overrides via Neovim's `after/` mechanism. | Currently only `after/lsp/info.md` — a placeholder. |
| `lazy-lock.json` | Plugin version pinning. Auto-managed by lazy.nvim. | Commit hashes for every installed plugin. |
| `spell/` | Custom spell file additions for Neovim's spell checker. | `en.utf-8.add` (custom words), `en.utf-8.add.spl` (compiled). |

## File Naming Conventions

| Convention | Example | Location |
|------------|---------|----------|
| **Snake case for Lua modules** | `telescope.lua`, `which-key.lua`, `nvim-cmp.lua`, `indent_line.lua` | `lua/tariq/plugins/` |
| **Descriptive plugin names** | `bufferline.lua`, `formatting.lua`, `todo-comments.lua` | `lua/tariq/plugins/` |
| **Standard core names** | `options.lua`, `remap.lua`, `commands.lua` | `lua/tariq/core/` |
| **Namespace subdirectory for LSP** | `lsp/lsp.lua`, `lsp/mason.lua` | `lua/tariq/plugins/lsp/` |

## Directory Naming Conventions

| Convention | Example | Location |
|------------|---------|----------|
| **Lowercase single-word directories** | `core/`, `plugins/`, `snippets/`, `spell/` | Top-level and under `lua/tariq/` |
| **Plugin-named subdirectory** | `lsp/` under `plugins/` | `lua/tariq/plugins/lsp/` |
| **Neovim standard `after/` directory** | `after/lsp/` | Top-level |

## Module Organization

**Modules are organized by concern, not by file type.** Each file has a single responsibility:

```
tariq.*                   — Namespace root (lazy.lua, lsp.lua)
tariq.core.*              — Base configuration (options, remap, commands)
tariq.plugins.*           — Per-plugin specs (auto-discovered by lazy.nvim)
tariq.plugins.lsp.*       — LSP-specific plugin specs
```

**How to add new code:**

| **Task** | **Location** | **Pattern** |
|----------|-------------|------------|
| Add a new Neovim option | `lua/tariq/core/options.lua` | `vim.opt.<name> = <value>` or `vim.g.<name> = <value>` |
| Add a new keymap | `lua/tariq/core/remap.lua` | `vim.api.nvim_set_keymap()` or `vim.keymap.set()` |
| Add a new autocommand or user command | `lua/tariq/core/commands.lua` | `vim.api.nvim_create_autocmd()` or `vim.api.nvim_create_user_command()` |
| Install a new plugin | Create a new file in `lua/tariq/plugins/<name>.lua` | Return a lazy.nvim spec table with `{ '<author/repo>', ... }` |
| Add LSP server or tool | Edit `lua/tariq/plugins/lsp/mason.lua` | Add server name to `ensure_installed` lists |
| Add custom LSP config per server | Create file in `after/lsp/` or use `lua/tariq/plugins/lsp/lsp.lua` | Use `vim.lsp.config.*` pattern |
| Add custom spell words | Edit `spell/en.utf-8.add` | Add word on a new line |
| Add snippets | Edit `snippets/<filetype>.lua` | Follow Luasnip snippet format |

**Plugin spec file structure** (convention observed across all files):

```lua
return {
  "<author>/<repo>",
  -- lazy-loading triggers
  event = "...",          -- or keys = {}, cmd = {}, ft = ""
  -- dependencies
  dependencies = { ... },
  -- configuration
  config = function()
    require("<plugin>").setup({ ... })
  end,
  opts = { ... },         -- or use opts table directly (lazy.nvim auto-calls .setup())
}
```
